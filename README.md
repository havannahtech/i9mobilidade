# i9 Mobilidade Elétrica

Site oficial estático da i9 Mobilidade Elétrica, publicado pelo Netlify a partir deste repositório.

- Site: https://i9mobilidade.com.br/
- Área interna: https://i9mobilidade.com.br/interno/
- Deploy: Netlify, branch `main`

## Área interna

A autenticação da área interna usa uma Netlify Function. A senha não é armazenada neste repositório; ela deve ser cadastrada no Netlify como variável de ambiente `I9_INTERNO_PASSWORD`.

Os módulos internos permanecem integrados à Central i9.
